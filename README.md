**MATLAB Data Analyzer**



**Project Overview**



MATLAB Data Analyzer is a graphical user interface (GUI) application developed using MATLAB GUIDE. It allows users to load CSV files, inspect datasets, calculate descriptive statistics, visualize numerical data, and export analysis results.



**Features**



-	Load data from CSV files



-	Preview original data in a table



-	Calculate summary statistics:



&#x09;-	Count



&#x09;-	Missing values



&#x09;-	Mean



&#x09;-	Minimum



&#x09;-	Maximum



&#x09;-	Standard deviation



- Plot data trends



- Generate histograms for selected numeric variables



- Export summary reports to CSV



- Export plots as PNG images



- Display error messages for unsupported or unreadable data files



**Technologies Used**



-	MATLAB R2024b



-	MATLAB GUIDE



-	MATLAB Tables



-	Data Visualization



-	CSV File Processing



**How to Run**



1\.	Open MATLAB.



2\.	Navigate to the project folder.



3\.	Open *DataAnalyzer\_Guide.fig* in GUIDE or open *DataAnalyzer\_Guide.m* in the MATLAB Editor.



4\.	Run the GUI.



5\.	Select a CSV file and explore the analysis features.



**Project Files**



-	*DataAnalyzer\_Guide.fig* — GUI layout



-	*DataAnalyzer\_Guide.m* — Application source code



-	*sample\_data.csv* — Sample input dataset



-	*summary\_report.csv* — Example exported report



-	*data\_plot.png* — Example exported visualization
