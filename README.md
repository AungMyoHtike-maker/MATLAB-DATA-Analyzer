**MATLAB Data Analyzer**



**Project Overview**



MATLAB Data Analyzer is a graphical user interface (GUI) application developed using MATLAB GUIDE. It allows users to load CSV files, inspect datasets, calculate descriptive statistics, visualize numerical data, and export analysis results.



**Features**



>>	Load data from CSV files



>>	Preview original data in a table



>>	Calculate summary statistics:



&#x09;=>	Count



&#x09;=>	Missing values



&#x09;=>	Mean



&#x09;=>	Minimum



&#x09;=>	Maximum



&#x09;=>	Standard deviation



&#x09;4.	Plot data trends



&#x09;5.	Generate histograms for selected numeric variables



&#x09;6.	Export summary reports to CSV



&#x09;7.	Export plots as PNG images



&#x09;8.	Display error messages for unsupported or unreadable data files



**Technologies Used**



>>	MATLAB R2024b



>>	MATLAB GUIDE



>>	MATLAB Tables



>>	Data Visualization



>>	CSV File Processing



**How to Run**



1\.	Open MATLAB.



2\.	Navigate to the project folder.



3\.	Open *DataAnalyzer\_Guide.fig* in GUIDE or open *DataAnalyzer\_Guide.m* in the MATLAB Editor.



4\.	Run the GUI.



5\.	Select a CSV file and explore the analysis features.



**Project Files**



>>	*DataAnalyzer\_Guide.fig* — GUI layout
